# 失敗トリガーと候補ルール

この表は仮説生成に使う。閾値は診断用の初期値であり、そのまま採用値にしない。

| 観測トリガー | 確認する証拠 | 候補ルール族 |
|---|---|---|
| 同一事業分類が保有の3分の2超 | 日次分類比率、損益寄与 | 同一分類上限、分類別サイズ上限 |
| 一分類が損失の60%以上 | 銘柄別・分類別損益 | 分類分散、相関上限、段階購入 |
| 候補が営業日の80%以上で存在 | 候補日数、空き枠日数 | 買いトリガー厳格化、現金維持条件 |
| 買い時点の短期騰落率や移動平均乖離が極端 | 20日・60日騰落率、MA乖離、ATR | 過熱上限、押し目待ち、再上昇確認 |
| 買い直後の最大逆行が大きい | MAE、保有初期の下落 | 分割購入、確認日数、初期ストップ |
| 200日線出口まで損失が拡大 | 売却理由、シグナルまでの日数、MFE/MAE | 補助MA、ATRストップ、トレーリング出口 |
| 期末清算で大半の損失が確定 | 期末保有、含み損、出口未成立 | 出口感応度、評価期間延長を別々に検証 |
| 開始日で結果が大きく変わる | 複数開始日の分布 | 段階投入、月次開始分散、確認トリガー |
| 売買回数が多く利益を失う | 回転率、再購入、費用感応度 | クールダウン延長、再エントリー条件 |
| 現金不足や納税売却が頻発 | 最低現金、税イベント | サイズ縮小、現金バッファ、納税資金ルール |
| 一銘柄が損益の大半を占める | 銘柄別寄与、最大ウェイト | 銘柄上限、リスク均等、最低分散数 |

## 仮説生成の順序

1. 観測値と取引明細を結び付ける。
2. 一つの観測に対して一つのルール族を選ぶ。
3. 閾値候補を探索前に有限集合で固定する。
4. 基準ルールと一変数比較する。
5. 開発期間で効果がなければ組み合わせへ進めない。
6. 改善した要素だけを二要素以内で組み合わせる。

## よく使う有限探索例

- 同一事業分類上限: `1`, `2`, 制約なし
- 60日騰落率上限: `40%`, `60%`, `80%`
- 200日線からの上方乖離上限: `15%`, `25%`, `35%`
- 押し目幅: `5%`, `10%`, `15%`
- 再上昇確認: 20日線回復、50日線回復、直近高値更新
- 補助出口: 50日線、100日線、ATR倍率 `2`, `3`, `4`

これらは探索空間の例であり、結果を見た後に都合のよい値だけ追加しない。絶対値が市場や銘柄に適さない場合は、事前にパーセンタイルやATR基準へ置き換える。

## 今回型のケース

同一分類への集中、ほぼ毎日の候補発生、買い時点の短期急騰が同時に見つかった場合は、次の順で試す。

1. 同一事業分類を1銘柄までにする。
2. 短期騰落率または移動平均乖離へ過熱上限を置く。
3. 押し目後の再上昇確認を追加する。
4. 200日線より速い補助出口を別ケースで試す。

業種を結果確認後の勝ち業種へ直接置き換える試行は、感応度分析として保存し、再現候補へ昇格させない。
